# RideMetrics — client features

- F1: Live tip-per-mile map — ops managers see average tip per mile by neighbourhood, refreshed every 5 minutes, on the operations dashboard.
- F2: Nightly driver scorecard — each morning every driver's trips, revenue and rating for the previous day appear in a scorecard report, built from the dispatch database and trip data.
- F3: Cancellation events — taxi devices start sending a new "trip cancelled" event, and cancellation rate by neighbourhood shows on the dashboards.
- F4: Surge alert — the ops lead gets a Teams message when ride count in any zone exceeds 150 in a 15-minute window.
- F5: Rider data erasure — the privacy officer enters a rider id and all of that rider's personal data is removed from the platform, with the request marked done once history is purged.
- F6: Fare restatement — finance picks a date range after a fare correction, the figures for that range are recomputed, and the revenue dashboards show the restated numbers.
