# Score review: "also builds" collapse + link picker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In a feature card's "Built by" rows, a component that also builds many other features shows one chip and a `…N more` button; clicking it shows the rest and turns into `show less`, which folds them again. On the score review, "+ Link a component" becomes a wide search box that filters components by name or container as you type.

**Architecture:** The score review page (`assets/score-review.html`) is generated by `scripts/build-template.mjs` from the mockup in `docs/mockups/estimate-workflow-mode/`, and the Component-based page (`assets/estimate-components.html`) is generated by `scripts/build-components-template.mjs` from `assets/score-review.html`. So one change in `build-template.mjs` reaches both pages. The chip markup moves into a new `scripts/template/also-builds.js` (spliced in by a `rep()`), its CSS into `scripts/template/also-builds.css`. Every chip is still rendered; the folded ones carry class `more` and are hidden by CSS until the row's `.calso` gets class `open`. The link picker `<select>` is replaced the same way by `scripts/template/link-picker.js` + `.css`; it only exists on the editable score review (the Component-based page is `FINAL` and draws no picker).

**Tech Stack:** Plain browser JS inside HTML templates, Node `node:test`, headless Chrome via `analyze-requirements/scripts/lib/cdp.mjs`.

**Spec:** none; the user's request (2026-10-20): "I want it collapsed as default, sample: `also build [feat-001]...7 more`, so when I click on 7 more it will expand the rest, I also can collapse it again." Applies to the score review and the estimate (Component-based) page. Second request (same day): "link component should be bigger and filterable, so I can type for filtering" — user chose a custom search box over the browser's `<datalist>` (keeps container groups, themed, wide).

## Global Constraints

- Never edit `assets/score-review.html` or `assets/estimate-components.html` by hand. Change the builders/template files, then regenerate both assets; `build-template.test.mjs` and `build-pages.test.mjs` pin the assets byte for byte.
- Show 1 chip when folded. Fold only when there are 3 or more other features (2 chips are shown as they are, no button).
- Button text: `…N more` (N = hidden chips, `…` is U+2026) when folded, `show less` when open.
- Template script gate (`quality-gates.test.mjs`, `TEMPLATE_LIMITS`): ≤22 lines per function, ≤3 params. Repo gates for `.mjs`: ≤20 lines/function, ≤3 params, nesting ≤2, ≤200 lines and ≤10 functions per file.
- No apostrophes inside template literals in template JS (the gate reads them as string quotes).
- Link picker: placeholder `+ Link a component… type to filter`; case-insensitive substring match on `"<component name> <container>"`; options grouped under their container; components that already build this feature are left out; ones that build nothing keep ` · builds nothing yet`; no match shows `No component matches`. Keys: ↓/↑ move, Enter links the highlighted one, Esc clears and closes; leaving the box closes it.
- Commits: Conventional Commits, subject ≤50 chars, no AI attribution trailers.
- Version: solution-architect 3.2.0 → 3.2.1 in `plugins/solution-architect/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`. Do not push (a plugin.json change on main publishes).

```js
// the other features a component builds: 3 or more fold to one chip and "…N more"
const ALSO_SHOWN = 1; const ALSO_FOLD = 3;
const alsoChip = (c, fold) => `<span class="cmini${fold ? ' more' : ''}" style="--sc:var(--s${sysNo(c)})" data-cap-chip="${c}" title="${esc(capById[c].name)}">${c}</span>`;
function alsoHtml(others) {
  if (!others.length) return '<span class="dim">only this feature</span>';
  const fold = others.length >= ALSO_FOLD;
  const chips = others.map((c, i) => alsoChip(c, fold && i >= ALSO_SHOWN)).join('');
  const more = fold ? `<button type="button" class="alsomore" data-also-more aria-expanded="false">…${others.length - ALSO_SHOWN} more</button>` : '';
  return `also builds ${chips}${more}`;
}
function toggleAlso(b) {
  const box = b.closest('.calso'); const open = box.classList.toggle('open');
  b.setAttribute('aria-expanded', String(open));
  b.textContent = open ? 'show less' : `…${box.querySelectorAll('.cmini.more').length} more`;
}
document.addEventListener('click', (e) => { const b = e.target.closest('[data-also-more]'); if (b) toggleAlso(b); });
```

Create `scripts/template/link-picker.js`:

```js
// "+ Link a component": a wide search box; typing filters by component or container name
const pickerHtml = (capId) => `<div class="lpick" data-lpick="${capId}"><input type="search" data-lpick-q placeholder="+ Link a component… type to filter" aria-label="Link a component" autocomplete="off"><div class="lpick-list hide" role="listbox"></div></div>`;
const pickOpt = (b) => `<div class="lpick-o" role="option" data-lpick-id="${b.id}">${esc(b.name)}${notAsked(b.id) ? '<span class="dim"> · builds nothing yet</span>' : ''}</div>`;
function pickList(capId, q) {
  const by = buildersOf(capId); const t = q.trim().toLowerCase();
  const hit = (b) => !by.includes(b.id) && `${b.name} ${b.container}`.toLowerCase().includes(t);
  const groups = [...new Set(COMPS.map((b) => b.container))].map((g) => [g, COMPS.filter((b) => b.container === g && hit(b))]).filter(([, bs]) => bs.length);
  if (!groups.length) return '<div class="lpick-none dim">No component matches</div>';
  return groups.map(([g, bs]) => `<div class="lpick-g">${esc(g)}</div>${bs.map(pickOpt).join('')}`).join('');
}
function openPick(inp) {
  const box = inp.closest('.lpick'); const list = $('.lpick-list', box);
  list.innerHTML = pickList(box.dataset.lpick, inp.value); list.classList.remove('hide');
  $('.lpick-o', list)?.classList.add('cur');
}
function movePick(list, d) {
  const os = [...list.querySelectorAll('.lpick-o')]; if (!os.length) return;
  const i = os.findIndex((o) => o.classList.contains('cur'));
  os.forEach((o) => o.classList.remove('cur'));
  const n = os[(i + d + os.length) % os.length]; n.classList.add('cur'); n.scrollIntoView({ block: 'nearest' });
}
function pickComp(capId, bid) { links[bid] = [...links[bid], capId]; relink(); }
function onPickKey(e) {
  const inp = e.target.closest?.('[data-lpick-q]'); if (!inp) return;
  const box = inp.closest('.lpick'); const list = $('.lpick-list', box); const cur = $('.lpick-o.cur', list);
  if (e.key === 'ArrowDown' || e.key === 'ArrowUp') { e.preventDefault(); if (list.classList.contains('hide')) openPick(inp); else movePick(list, e.key === 'ArrowDown' ? 1 : -1); }
  if (e.key === 'Enter') { e.preventDefault(); if (cur && !list.classList.contains('hide')) pickComp(box.dataset.lpick, cur.dataset.lpickId); }
  if (e.key === 'Escape') { inp.value = ''; list.classList.add('hide'); }
}
const pickInput = (e) => e.target.closest?.('[data-lpick-q]');
document.addEventListener('focusin', (e) => { const q = pickInput(e); if (q) openPick(q); });
document.addEventListener('input', (e) => { const q = pickInput(e); if (q) openPick(q); });
document.addEventListener('focusout', (e) => { const q = pickInput(e); if (q) $('.lpick-list', q.closest('.lpick')).classList.add('hide'); });
document.addEventListener('keydown', onPickKey);
// mousedown would blur the box and close the list before the click lands
document.addEventListener('mousedown', (e) => { if (e.target.closest('.lpick-o')) e.preventDefault(); });
document.addEventListener('click', (e) => { const o = e.target.closest('.lpick-o'); if (o) pickComp(o.closest('.lpick').dataset.lpick, o.dataset.lpickId); });
```
