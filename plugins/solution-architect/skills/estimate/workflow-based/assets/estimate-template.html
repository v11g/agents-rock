A system has the workflows the PO's document draws; each feature sits on the steps it serves, or on none when its system has no workflow. The price covers every feature on this page, and each milestone lists the features it finishes.

Summary

The price for this scope, stated once. Lead with the range; if a single fixed number is unavoidable, quote the confident figure.

By system

The systems and workflows the PO confirmed. The price is quoted for the whole project and per milestone, not per system: shared features such as notifications serve several systems at once. Hours and tasks per feature are on the Component-based page.

Workflows & features

Every feature sits on the workflow step it serves. Hover a diagram box or a feature to see the connections; click to pin them. A pinned step opens on the Component-based page with its hours and tasks.

Milestones

What the client can use at the end of each milestone. A feature is finished when everything it needs is built. Each milestone's range is its share of the build applied to the project range.

Assumptions & exclusions

What this price rests on, and what it does not cover. Shared word for word with the proposal.
