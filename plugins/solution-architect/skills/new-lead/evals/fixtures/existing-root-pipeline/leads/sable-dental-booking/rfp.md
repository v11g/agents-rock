# Sable Dental — online booking (notes from the intro call, 2026-09-15)

Sable Dental runs 11 practices in the Midlands. Patients book by phone;
each practice keeps its own paper-ish diary inside their PMS (Dentally).

What they asked for:

- Patients book, reschedule and cancel online, per practice.
- Slots must respect each dentist's real availability in Dentally.
- SMS reminders 48h and 2h before an appointment.
- One admin view across all 11 practices for the ops manager.

Budget was described as "circa 150k, and we would rather phase it".
They want the first two practices live before the March recall season.
